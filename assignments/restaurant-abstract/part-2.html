ממשק (Interface)

חוזה שמגדיר רשימה של פעולות: רק חתימות, בלי גוף ובלי תכונות. מחלקה שמממשת את הממשק מתחייבת לממש את כל הפעולות שבו, כ-public. ירושה עונה על השאלה "מה העצם הוא", וממשק על "מה העצם יודע לעשות". למחלקה יש מחלקת בסיס אחת בלבד, אבל היא יכולה לממש כמה ממשקים.

Example
interface IDiscountable
{
    double GetHappyHourPrice();   // a signature only
}

// one base class, then the interfaces, separated by commas
class Drink : MenuItem, IDiscountable
{
    // ...
    public double GetHappyHourPrice()
    {
        return GetPrice() - 5;
    }
}

ברשימה List<MenuItem> חלק מהפריטים מממשים את הממשק וחלק לא. האופרטור is שואל את העצם האמיתי: "אתה מממש את זה?". רק אחרי שהתשובה היא כן, ממירים כדי להגיע לפעולה של הממשק.

Example
foreach (MenuItem item in menu)
{
    if (item is IDiscountable)
    {
        IDiscountable deal = (IDiscountable)item;
        Console.WriteLine(item.Name + ": " + deal.GetHappyHourPrice());

}

אפשר גם בשורה אחת: if (item is IDiscountable deal). שתי הצורות עושות אותו דבר.

לפני שמשנים: נחשו

עוד לא מימשתם שום ממשק. מה יקרה אם תכתבו עכשיו את הקוד הזה ותריצו אותו?

Main
List<MenuItem> sorted = new List<MenuItem>(menu);
sorted.Sort();

Unhandled exception
System.InvalidOperationException: Failed to compare two elements in the array.

הקוד מתקמפל, ונופל רק כשהוא רץ. Sort() קיימת לכל רשימה, ולכן הקומפיילר לא מתלונן. אבל כשהיא מנסה להשוות שני פריטים, היא מגלה ש-MenuItem לא חתמה על החוזה "אני יודע להשוות את עצמי". היא לא יודעת אם להשוות לפי מחיר, לפי שם או לפי משהו אחר. את זה אתם מגדירים עכשיו.

  1. MenuItem מממשת את IComparable<MenuItem>: הוסיפו את זה אחרי שם המחלקה, עם נקודתיים.
  2. כתבו ב-MenuItem את הפעולה public int CompareTo(MenuItem other): אם המחיר שלי (GetPrice()) קטן מהמחיר של other, מחזירים -1. אם הוא גדול, מחזירים 1. אם הם שווים, מחזירים 0.
  3. במחלקה Program כתבו פעולה סטטית PrintMenuByPrice(List<MenuItem> menu): היא יוצרת עותק של הרשימה, ממיינת את העותק, ומדפיסה כותרת ------ MENU BY PRICE ------ ואחריה את הפריטים (בלי מספור).

שאלה למחשבה: למה ממיינים עותק ולא את menu עצמה?

המלצר מוסיף פריטים להזמנה לפי המספר שלהם בתפריט (menu[num - 1]). אם נמיין את menu עצמה, השניצל כבר לא יהיה פריט 1, והמלצר יזמין את הפריט הלא נכון.

שימו לב: העותק הוא רשימה חדשה, אבל הפריטים בה הם אותם עצמים בדיוק. אין שניצל שני בזיכרון, יש שתי רשימות שמצביעות על אותו שניצל (כמו בצבירה).
