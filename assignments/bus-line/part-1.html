קו אוטובוס, חלק 1: בונים את הקו

בונים תוכנית אחת, שלב אחרי שלב: קו אוטובוס שנשמר כשרשרת של תחנות. כל תחנה יודעת כמה דקות נוסע האוטובוס אליה מהתחנה הקודמת. בחלק הזה בונים את התחנה ואת הקו, ומחשבים זמני נסיעה.

  • זמן משוער: כשעה, בקצב שלכם
  • שפה: C#, אפליקציית Console
  • הגשה: בסוף חלק 2

לפני שמתחילים

  • פתחו פרויקט Console חדש, והוסיפו לו את ספריית המחלקות של משרד החינוך (Unit4.CollectionsLib), כמו בשיעורים על שרשרת חוליות.
  • בראש הקובץ: using Unit4.CollectionsLib;
איך עובדים: בסוף כל שלב יש Main ופלט צפוי. הריצו והשוו שורה אחרי שורה, ועברו לשלב הבא רק כשהפלט זהה בדיוק. סריקות הולכות עם pos; רק הוספה או הוצאה משנות את first.

תזכורת קצרה

קראו, ואז ענו על הבוחן הקצר שבסוף. בשלבים יש קישורים חזרה לכאן.

1

החוליה (Node)

חוליה מחזיקה ערך והפניה לחוליה הבאה. בחוליה האחרונה ההפניה היא null. את כל השרשרת מכירים דרך החוליה הראשונה בלבד.

פעולהמה היא עושה
new Node<T>(x)חוליה עם הערך x, בלי חוליה הבאה
new Node<T>(x, next)חוליה עם הערך x, שמפנה ל-next
GetValue(), SetValue(x)הערך שבחוליה
GetNext(), SetNext(n)החוליה הבאה
HasNext()האם יש חוליה הבאה
2

הליכה על שרשרת

הולכים עם משתנה עזר pos, ולא מזיזים את first. ‏pos != null עובר על כל החוליות; ‏pos.HasNext() עוצר על האחרונה, כשצריך לעשות בה משהו (למשל להוסיף אחריה).

The walk
Node<Stop> pos = first;
while (pos != null)
{
    Stop s = pos.GetValue();
    // ... look at s ...
    pos = pos.GetNext();
}
3

שרשרת בתוך מחלקה

במחלקה, first הוא תכונה פרטית. הפעולות של המחלקה מציבות בו בעצמן, ולכן הן לא מחזירות אותו. הערך בכל חוליה הוא עצם, ולכן מבקשים ממנו את מה שצריך: pos.GetValue().GetName().

אם פעולת סריקה מזיזה את first במקום pos, השרשרת אובדת לתמיד.

בוחן בדיקה עצמית

השלבים

הזמנים ליד כל שלב הם הערכה בלבד, לא מגבלה. סמנו כל שלב שסיימתם, וההתקדמות תופיע בפתק בצד.

0

חימום: אורך והוספה בסוף

כ-10 דקות
עיקרון: הליכה על שרשרת

בסוף השלב: שתי פעולות על שרשרת של מספרים: אחת סופרת חוליות, והשנייה מוסיפה חוליה בסוף.

צריכים תזכורת?החוליההליכה על שרשרת
  1. כתבו פעולה סטטית int Length(Node<int> first) שמחזירה את מספר החוליות.
  2. כתבו פעולה סטטית Node<int> AddLast(Node<int> first, int x) שמוסיפה חוליה עם x בסוף, ומחזירה את החוליה הראשונה. בשרשרת ריקה, החוליה החדשה היא השרשרת.
  3. הוסיפו את הפעולה Print משיעור 1. נסו לכתוב בלי להסתכל בשיעורים.
Main
Node<int> first = null;
Console.WriteLine(Length(first));
first = AddLast(first, 7);
first = AddLast(first, 2);
first = AddLast(first, 9);
Print(first);
Console.WriteLine(Length(first));
Expected output
0
7 -> 2 -> 9 -> null
3

טעות נפוצה: נחשו מה קורה

תלמיד כתב בשורה הראשונה AddLast(first, 7);, בלי first =. שתי השורות הבאות נשארו כמו שהן. מה תדפיס Print(first)?

Output
2 -> 9 -> null

ה-7 אבד. השרשרת הייתה ריקה, ולכן AddLast יצרה חוליה חדשה והחזירה אותה. אף אחד לא שמר אותה, ו-first נשאר null. השורה הבאה התחילה שרשרת חדשה מ-2. פעולה שעשויה לשנות את הראש מחזירה אותו, וחובה להציב את התוצאה.

רמז

ב-AddLast: יוצרים את החוליה החדשה. אם first == null, מחזירים אותה. אחרת הולכים עם pos.HasNext() עד החוליה האחרונה, ומחברים אליה את החדשה.

תחנה (Stop)

כ-10 דקות
עיקרון: מחלקה

בסוף השלב: מחלקה של תחנה, עם שם, ומספר הדקות שהאוטובוס נוסע אליה מהתחנה הקודמת.

צריכים תזכורת?תקציר: מחלקה ועצם (PDF)
  1. תכונות פרטיות: name (מחרוזת) ו-minutes (שלם): הדקות מהתחנה הקודמת.
  2. פעולה בונה Stop(string name, int minutes), ופעולות GetName(), GetMinutes(), SetMinutes(int minutes).
  3. ToString() שמחזירה את התחנה בדיוק בפורמט שבפלט הצפוי.
Main
Stop a = new Stop("Park", 4);
Console.WriteLine(a);
Console.WriteLine(a.GetName() + " " + a.GetMinutes());
a.SetMinutes(7);
Console.WriteLine(a);
Expected output
Park (4 min)
Park 4
Park (7 min)

כ-20 דקות
עיקרון: שרשרת כתכונה של מחלקה

בסוף השלב: קו שאפשר להוסיף לו תחנות בסוף, לספור אותן ולהדפיס את המסלול.

צריכים תזכורת?שרשרת בתוך מחלקההליכה על שרשרת
  1. תכונות פרטיות: number (מחרוזת, מספר הקו) ו-Node<Stop> first.
  2. פעולה בונה BusLine(string number), עם שרשרת ריקה.
  3. void AddStop(string name, int minutes): מוסיפה תחנה בסוף. לתחנה הראשונה בקו יש תמיד 0 דקות, לא משנה מה התקבל: אין תחנה לפניה.
  4. int CountStops(): כמה תחנות יש בקו.

Console.WriteLine(line.CountStops());

זמנים

כ-20 דקות
עיקרון: סריקה עם סכום מצטבר

בסוף השלב: הקו יודע כמה זמן לוקחת כל הנסיעה, וכמה זמן לוקח להגיע לכל תחנה מהתחנה הראשונה.

צריכים תזכורת?הליכה על שרשרתשרשרת בתוך מחלקה
  1. int TotalMinutes(): הדקות מהתחנה הראשונה עד האחרונה.
  2. int TimeTo(string name): הדקות מהתחנה הראשונה עד התחנה הזו. אם אין תחנה כזו, -1.
  3. void PrintTimes(): כל תחנה בשורה משלה, עם הזמן שלה מהתחנה הראשונה, כמו בפלט. מעבר אחד על השרשרת.

מכאן והלאה, השלבים משתמשים בפעולה הזו כדי לבנות את אותו קו. העתיקו אותה למחלקה Program:

Build
static BusLine Build()
{
    BusLine line = new BusLine("5");
    line.AddStop("Central", 0);
    line.AddStop("Park", 4);
    line.AddStop("Library", 6);
    line.AddStop("Market", 3);
    line.AddStop("Station", 5);
    return line;
}
Main
BusLine line = Build();
Console.WriteLine(line);
Console.WriteLine(line.TotalMinutes());
Console.WriteLine(line.TimeTo("Library") + " " + line.TimeTo("Central") + " " + line.TimeTo("Zoo"));
line.PrintTimes();

לפני שמריצים: נחשו

בקו: Central, ‏Park (4), ‏Library (6), ‏Market (3), ‏Station (5). מה יחזירו הקריאות האלה?

18
10 0 -1

הזמן לתחנה כולל את הדקות שלה עצמה: אל Library נוסעים 4 דקות עד Park ועוד 6, כלומר 10. לכן מוסיפים את הדקות של התחנה לפני שבודקים אם זו התחנה המבוקשת. אל Central, התחנה הראשונה, הזמן הוא 0.

רמז

שלוש הפעולות בנויות אותו דבר: pos הולך על כל השרשרת, ו-sum מצטבר. ב-TimeTo מחזירים את sum ברגע שמוצאים את השם. ב-PrintTimes מדפיסים את sum אחרי כל תחנה. אל תקראו ל-TimeTo בתוך הלולאה: זה היה מעבר על השרשרת לכל תחנה.
