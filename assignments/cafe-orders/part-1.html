בית קפה, חלק 1: בונים את המערכת

בונים תוכנית אחת, שלב אחרי שלב: בית קפה שבו ההזמנות מחכות בתור, וההזמנות שהוגשו נכנסות למחסנית, כך שאפשר לבטל את האחרונה שהוגשה. בחלק הזה בונים את ההזמנה, את בית הקפה ואת ההגשה.

  • זמן משוער: כשעה, בקצב שלכם
  • שפה: C#, אפליקציית Console
  • הגשה: בסוף חלק 2

לפני שמתחילים

  • פתחו פרויקט Console חדש, והוסיפו לו את ספריית המחלקות של משרד החינוך (Unit4.CollectionsLib), כמו בשיעורים על המחסנית והתור.
  • בראש הקובץ: using Unit4.CollectionsLib;
  • מופיעה השגיאה CS0104 ("Stack is an ambiguous reference")? זה כי גם ב-System.Collections.Generic יש Stack<T>. הוסיפו לקובץ הפרויקט (.csproj) את השורה <Using Remove="System.Collections.Generic" /> בתוך <ItemGroup>, כמו בשיעור 2 על המחסנית.
איך עובדים: בסוף כל שלב יש Main ופלט צפוי. הריצו והשוו שורה אחרי שורה, ועברו לשלב הבא רק כשהפלט זהה בדיוק. כל פעולה שרק קוראת מבנה צריכה להשאיר אותו כמו שהיה.

לעבור בלי להרוס

אין דרך להסתכל על איבר באמצע המבנה בלי להוציא את מה שלפניו. לכן מוציאים הכול למבנה עזר, ובסוף מחזירים. תור מחזירים בעזרת תור, ומחסנית בעזרת מחסנית, ואז הסדר נשמר.

The pattern for a queue
Queue<Order> temp = new Queue<Order>();
while (!waiting.IsEmpty())
{
    Order o = waiting.Remove();
    // ... look at o ...
    temp.Insert(o);
}
while (!temp.IsEmpty())
    waiting.Insert(temp.Remove());

חימום: לספור בלי להרוס

כ-10 דקות
עיקרון: מבנה עזר והחזרה

בסוף השלב: שתי פעולות שסופרות כמה איברים יש במחסנית ובתור, ומשאירות אותם בדיוק כמו שהיו.

צריכים תזכורת?לעבור בלי להרוסתקציר: מעבר על מחסנית (PDF)
  1. כתבו פעולה סטטית int CountS(Stack<int> s) שמחזירה את מספר האיברים במחסנית.
  2. כתבו פעולה סטטית int CountQ(Queue<int> q) שמחזירה את מספר האיברים בתור.
  3. נסו בלי להסתכל בשיעורים. בסוף, כל מבנה חוזר בדיוק לסדר שבו היה.
Main
Stack<int> s = new Stack<int>();
Queue<int> q = new Queue<int>();
for (int i = 1; i <= 4; i++)
{
    s.Push(i);
    q.Insert(i * 10);
}
Console.WriteLine(CountS(s) + " " + CountQ(q));
Console.WriteLine(s.Top() + " " + q.Head());

לפני שמריצים: נחשו

השורה האחרונה ב-Main מדפיסה את הראש של המחסנית ואת הראש של התור, אחרי שספרתם אותם. מה היא תדפיס?

Expected output
4 4
4 10

הספירה לא שינתה כלום. בראש המחסנית עדיין 4 (האחרון שנכנס), ובראש התור עדיין 10 (הראשון שנכנס). אם אצלכם מתקבלת שגיאה של מבנה ריק, או מספר אחר, הספירה שלכם הרסה את המבנה או הפכה את הסדר שלו.

בית קפה (Cafe)

כ-20 דקות
עיקרון: תור כתכונה של מחלקה

בסוף השלב: בית קפה שמקבל הזמנות, נותן לכל אחת מספר משלה, יודע כמה הזמנות מחכות ומדפיס אותן לפי הסדר.

צריכים תזכורת?פעולות התורלעבור בלי להרוס
  1. תכונות: name (מחרוזת), Queue<Order> waiting, Stack<Order> served, ו-nextId: המספר של ההזמנה הבאה.
  2. פעולה בונה Cafe(string name): תור ומחסנית ריקים, ו-nextId מתחיל ב-1.
  3. Order AddOrder(string item, int minutes): יוצרת הזמנה עם המספר הבא, מקדמת את nextId, מכניסה את ההזמנה לסוף התור ומחזירה אותה.
  4. int CountWaiting(): כמה הזמנות מחכות. התור נשאר כמו שהיה.
  5. void PrintWaiting(): שורת כותרת עם שם בית הקפה, ואחריה כל הזמנה בשורה משלה עם שני רווחים בהתחלה. התור נשאר כמו שהיה.
Main
Cafe c = new Cafe("Cafe Yam");
c.AddOrder("Latte", 4);
c.AddOrder("Toast", 7);
Order o = c.AddOrder("Tea", 2);
Console.WriteLine(o.GetId());
Console.WriteLine(c.CountWaiting());
c.PrintWaiting();
Expected output
3
3
Cafe Yam - waiting:
  #1 Latte (4 min)
  #2 Toast (7 min)
  #3 Tea (2 min)

טעות נפוצה: נחשו מה קורה

תלמידה כתבה את PrintWaiting, אבל החזירה את התור בעזרת מחסנית במקום תור. בתור היו שלושה מספרים: 1 בראש, אחריו 2, ובסוף 3. מה קורה לתור אחרי ההחזרה?

Output
3 2 1

המחסנית הופכת את הסדר. מה שיצא ראשון מהתור (1) נכנס לתחתית המחסנית, ויוצא ממנה אחרון. ההדפסה עצמה נראית תקינה, אבל מעכשיו ההזמנה האחרונה תוגש ראשונה. לכן תור מחזירים בעזרת תור.

הגשה

כ-15 דקות
עיקרון: תור ומחסנית יחד

בסוף השלב: אפשר להגיש את ההזמנה שבראש התור. היא עוברת למחסנית של ההזמנות שהוגשו, ואפשר לראות מי הוגשה אחרונה ובכמה דקות של עבודה התור מחכה.

צריכים תזכורת?פעולות המחסנית והתורתקציר: מחסנית (PDF)
  1. Order ServeNext(): מוציאה את ההזמנה שבראש התור, מכניסה אותה ל-served ומחזירה אותה. אם התור ריק, מחזירה null.
  2. Order LastServed(): ההזמנה האחרונה שהוגשה, בלי להוציא אותה. אם לא הוגש כלום, null.
  3. int TotalWaitTime(): סכום הדקות של כל ההזמנות שמחכות. התור נשאר כמו שהיה.

מכאן והלאה, השלבים משתמשים בפעולה הזו כדי לבנות את אותו בית קפה. העתיקו אותה למחלקה Program:

Build
static Cafe Build()
{
    Cafe c = new Cafe("Cafe Yam");
    c.AddOrder("Latte", 4);
    c.AddOrder("Toast", 7);
    c.AddOrder("Tea", 2);
    c.AddOrder("Latte", 4);
    c.AddOrder("Salad", 9);
    return c;
}
Main
Cafe c = Build();
Console.WriteLine(c.TotalWaitTime());
Console.WriteLine(c.ServeNext());
Console.WriteLine(c.ServeNext());
Console.WriteLine(c.LastServed());
Console.WriteLine(c.CountWaiting() + " " + c.TotalWaitTime());
Cafe empty = new Cafe("Empty");
Console.WriteLine(empty.ServeNext() == null);

לפני שמריצים: נחשו

בתור יש חמש הזמנות: 4, 7, 2, 4 ו-9 דקות. אחרי שתי הגשות, מה תדפיס השורה c.CountWaiting() + " " + c.TotalWaitTime()?

Expected output
26
#1 Latte (4 min)
#2 Toast (7 min)
#2 Toast (7 min)
3 15
True

הוגשו הראשונות בתור: Latte (4) ו-Toast (7), לפי סדר ההגעה. נשארו Tea, ‏Latte ו-Salad: ‏2 + 4 + 9 = 15. שימו לב שהשורה השלישית והרביעית זהות: LastServed() רק מציצה ב-Top(), ולא מוציאה.

רמז

ב-ServeNext בודקים קודם waiting.IsEmpty(). ב-LastServed משתמשים ב-Top(), לא ב-Pop(). ‏TotalWaitTime בנויה בדיוק כמו CountWaiting, רק סוכמת דקות במקום לספור.
