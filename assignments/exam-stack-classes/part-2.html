תרגול למבחן, חלק 2: מחלקות ועצמים

שאלות בסגנון הבגרות על מחלקות: כתיבת מחלקה, מערך של עצמים, עצם מורכב ומעקב אחר הפניות. בכל שאלה יש רמזים, ובדף נפרד יש פתרונות מלאים ורשימת בדיקה עצמית.

  • שאלות: 6
  • בוחרים: כמה שרוצים, בכל סדר
  • שפה: C#

מחלקות ועצמים, בסגנון הבגרות

  • השאלות בנויות כמו שאלות על מחלקות בבגרות: נותנים מחלקה עם התכונות שלה וממשק חלקי, ומבקשים "ממשו" פעולה בונה, פעולות פנימיות ופעולה חיצונית על מערך.
  • "פעולה פנימית" נכתבת בתוך המחלקה. "פעולה חיצונית" היא public static, מחוץ למחלקה, ומשתמשת רק בפעולות הממשק.
  • "חובה להשתמש בפעולה מסעיף..." = פתרון שלא משתמש בה אינו מלא, גם אם הקוד עובד. מותר להשתמש בפעולות מהממשק ומסעיפים קודמים בלי לממש אותן שוב.
  • כתבו במחברת. הפתרונות נמצאים בדף נפרד, שהמורה ייתן לכם. השאלות על המחסנית נמצאות בחלק 1.

מחלקה: מוצר בחנות

כ-35 דקות

צריכים תזכורת?תקציר: מחלקה ועצם (PDF)תקציר: מערך של עצמים (PDF)

חנות רוצה לנהל את המוצרים שלה. לכל מוצר נשמרים: שם (מחרוזת), מחיר ליחידה (ממשי) וכמות במלאי (שלם).

א. כתבו את המחלקה Product, הכוללת:

  1. כותרת המחלקה ותכונותיה.
  2. פעולה בונה שמקבלת את שלושת הנתונים ומאתחלת את התכונות.
  3. פעולה מאחזרת (Get) לכל תכונה, ופעולה קובעת SetQuantity.

ב. הוסיפו למחלקה פעולה פנימית double TotalValue(), שמחזירה את שווי המלאי של המוצר: המחיר כפול הכמות.

ג. הוסיפו למחלקה פעולה פנימית שכותרתה:

כותרת
public bool Sell(int amount)

אם יש במלאי לפחות amount יחידות, הפעולה מורידה אותן מהמלאי ומחזירה true. אחרת, המלאי לא משתנה והפעולה מחזירה false.

ד. כתבו פעולה חיצונית שכותרתה:

כותרת
public static string MostValuable(Product[] products)

הפעולה מחזירה את שם המוצר ששווי המלאי שלו הגבוה ביותר. הניחו שהמערך מלא (אין בו null) ושיש מוצר אחד כזה בלבד. חובה להשתמש בפעולה מסעיף ב.

דוגמה
Pen  4.5 x 100  -> 450
Bag  80  x 7    -> 560
Book 45  x 10   -> 450
MostValuable(...)  ->  "Bag"
רמז 1

בסעיף ד שמרו את האינדקס (או העצם) של המוצר הטוב ביותר עד עכשיו, ולא רק את השווי שלו: בסוף צריך להחזיר את השם.

המחלקה Student מייצגת תלמיד. הממשק שלה:

פעולהתיאור
Student(string name, double average)פעולה בונה
string GetName()מחזירה את שם התלמיד
double GetAverage()מחזירה את הממוצע של התלמיד

המחלקה Classroom מייצגת כיתה. התכונות שלה:

Classroom
public class Classroom
{
    private string className;     // e.g. "11A"
    private Student[] students;   // the students are in cells 0 .. count-1
    private int count;            // how many students are in the class now
    ...
}

א. ממשו פעולה בונה שכותרתה Classroom(string className, int capacity). בתחילה אין תלמידים בכיתה; capacity הוא המספר המרבי של תלמידים.

ב. הוסיפו פעולה פנימית bool Add(Student st): אם יש מקום בכיתה, הפעולה מוסיפה את התלמיד ומחזירה true. אחרת מחזירה false.

ג. הוסיפו פעולה פנימית double Average(), שמחזירה את הממוצע של הממוצעים של התלמידים בכיתה. הניחו שיש בכיתה לפחות תלמיד אחד.

ד. הוסיפו פעולה פנימית int CountAbove(double g), שמחזירה כמה תלמידים בכיתה ממוצעם גדול מ-g.

ה. הניחו שבמחלקה יש גם string GetClassName(). כתבו פעולה חיצונית שכותרתה:

כותרת
public static string BestClass(Classroom[] classes)

הפעולה מחזירה את שם הכיתה שהממוצע שלה הגבוה ביותר. הניחו שכל הכיתות לא ריקות ושיש כיתה אחת כזו בלבד. חובה להשתמש בפעולה מסעיף ג.

דוגמה
11A (capacity 3): Noa 92, Eli 78, Tal 85   Add(Gil) -> false
   Average() -> 85    CountAbove(80) -> 2
11B: Ron 88, Maya 90   Average() -> 89
BestClass(...) -> "11B"
רמז 1

הלולאות במחלקה רצות עד count, לא עד students.Length: התאים שאחרי count הם null, ו-GetAverage() עליהם תזרוק NullReferenceException.

המחלקה Train מייצגת נסיעת רכבת. התכונות שלה:

Train
public class Train
{
    private int number;

א. הוסיפו למחלקה Time פעולה פנימית int ToMinutes(), שמחזירה כמה דקות עברו מחצות. למשל עבור 08:45 היא מחזירה 525.

ב. ממשו פעולה בונה למחלקה Train שכותרתה:

כותרת
public Train(int number, string destination, int depHour, int depMin, int arrHour, int arrMin)

ג. הוסיפו ל-Train פעולה פנימית int Duration(), שמחזירה את משך הנסיעה בדקות. חובה להשתמש בפעולה מסעיף א.

ד. הוסיפו ל-Train פעולה פנימית void Delay(int minutes), שמאחרת את שעת היציאה ואת שעת ההגעה ב-minutes דקות. הניחו שהנסיעה נשארת באותו היום.

דוגמה
Train t = new Train(512, "Haifa", 8, 45, 10, 5);
t.Duration()  ->  80
t.Delay(20);    departure 09:05, arrival 10:25, Duration() -> 80
רמז 1

ב-Delay: הופכים לדקות, מוסיפים, ומחזירים לשעה ודקה: שעה = total / 60, דקה = total % 60. כדאי לכתוב פעולת עזר שעושה את זה לעצם Time אחד, ולזמן אותה פעמיים.

ה. תלמיד כתב את הפעולה הבונה המעתיקה הבאה:

    this.number = other.number;
    this.destination = other.destination;
    this.departure = other.departure;

ב. הוסיפו ל-Hotel פעולה פנימית שכותרתה:

הפעולה מכניסה את האורח לחדר הפנוי הראשון שהמחיר שלו ללילה לא גבוה מ-maxPrice, ומחזירה את מספר החדר. אם אין חדר כזה, היא מחזירה -1. חובה להשתמש בפעולה מסעיף א.

המחלקה Song מייצגת שיר. הממשק שלה:

פעולהתיאור
Song(string title, string artist, int seconds)פעולה בונה

בכל הסעיפים songs הוא מערך מלא (אין בו null). האמן יכול להופיע בכמה מקומות במערך.

המערך בדוגמאות
songs:  Rain (Noa, 210)   Home (Idan, 185)   Light (Noa, 240)   Road (Idan, 300)   Sky (Shir, 150)

א. כתבו פעולה חיצונית int TotalTime(Song[] songs, string artist), שמחזירה את סך השניות של כל השירים של האמן. אם אין לו שירים, מחזירה 0.

דוגמה
TotalTime(songs, "Noa") -> 450      TotalTime(songs, "Avi") -> 0

ב. כתבו פעולה חיצונית string TopArtist(Song[] songs), שמחזירה את שם האמן שסך זמן השירים שלו הגדול ביותר. הניחו שיש אמן אחד כזה. חובה להשתמש בפעולה מסעיף א.

דוגמה
TopArtist(songs) -> "Idan"     (Idan 485, Noa 450, Shir 150)
רמז 1

לכל שיר במערך, מחשבים את TotalTime של האמן שלו. אמן שמופיע כמה פעמים יחושב כמה פעמים, וזה בסדר: התוצאה זהה.

ג. כתבו פעולה חיצונית bool HasDuplicates(Song[] songs), שמחזירה true אם יש במערך שני שירים עם אותו שם ואותו אמן.

ד. כתבו פעולה חיצונית שכותרתה:

כותרת
public static Song[] LongerThan(Song[] songs, int sec)

הפעולה מחזירה מערך חדש, בגודל המדויק, עם השירים שאורכם גדול מ-sec, באותו הסדר שבו הם מופיעים ב-songs.

דוגמה
LongerThan(songs, 200) -> [Rain, Light, Road]   (length 3)
רמז 1

"בגודל המדויק": קודם סופרים כמה שירים מתאימים, יוצרים מערך בגודל הזה, ואז עוברים שוב וממלאים אותו עם אינדקס נפרד (k).
