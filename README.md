# מבני נתונים · כיתה יא'

Course site for 11th-grade Data Structures (Hebrew): lessons, self-check questions, a practice-sheet generator and summary PDFs.

Live: https://shimimahluf.github.io/cs-materials/

The page is generated — edit the sources in `New\Data Structures\_Setup\website` and rebuild with `assemble.py --static`, not `index.html` by hand.

## Interactive assignments (`assignments/`)

Hand-written pages, not generated by `assemble.py` — edit them directly.

- `assignments/index.html` lists every assignment with tag filters; the list comes from `assignments/catalog.js`.
- `assignments/assets/assignment.css` + `assignment.js` are shared by all assignment pages (code highlighting, hints, quiz, predict-then-reveal, progress ticket, part navigation).
- One folder per assignment, one page per part (`part-1.html`, `part-2.html`, …).
- Teacher solutions are never committed here (the repo is public).
